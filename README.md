# Bakery Sales Analysis

A beginner Python project using fictional bakery sales data.

## Project goals
- Calculate total sales revenue
- Find the best-selling products
- Compare daily sales
- Practise Python and pandas

## Status
In progress — learning project.

## Data
All data will be fictional. No private business or customer information is used.
    A beginner Python project for analysing bakery sales using sample data
## Results

Based on fictional sales data:
- Total revenue: 2,395,000 UZS
- Total units sold: 156
- Best-selling product by quantity: Napoleon (67 units)
- Highest-revenue day: 3 October 2026 (862,000 UZS)

## How to run

Install pandas:
pip install pandas

Run the analysis:
python analysis.py

The analysis also runs automatically through GitHub Actions.
